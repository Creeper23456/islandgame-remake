# 序章手动验收

按 [README](../README.md#在-linux-上构建和运行) 构建后，从桌面终端启动，保持游戏窗口获得焦点。不要加 `--first-frame`；它是首帧探针，不是游玩模式。使用独立的安装盘副本，因为「新的开始」会重置临时存档。按原界面处理免责声明，不输入激活码，不改授权文件。

| PC 键位 | 游戏动作 |
| --- | --- |
| 空格／右 Shift／鼠标左键 | 原 OK 键：进入标题菜单、确认选项、推进对白 |
| Enter／小键盘 Enter／Tab | 左功能键（例如「物品」） |
| Esc／鼠标右键 | 右功能键（例如「返回」或「菜单」） |
| A／D 或 左／右 | 转身，场景视角随之变化 |
| W／S 或 上／下 | 前进／后退；快速按两次前进键可奔跑，按后退键停止奔跑 |
| 主键盘数字 1–9、0 | 原手机数字键（小键盘仍按拨号盘位置映射；PageUp／PageDown 为 `#`／`*`） |
| 鼠标左右移动 | 场景可操作时捕获指针，按 `UpdatePlayer` 入口处的精确增量直接转动朝向（玩家 +0x278，12 位角）；位置、碰撞、镜头和脚本仍走原路径；菜单、对白、地图、暂停时恢复普通指针 |

鼠标转向可用环境变量调整：`ISLAND_MOUSE_LOOK=0` 关闭，`ISLAND_MOUSE_STEP=<计数>` 设置转一整圈所需的鼠标计数（200..20000，默认 2000），`ISLAND_MOUSE_INVERT=1` 反向。已验证：无头运行下注入 -300 计数，朝向精确增加 614 单位。

显示：客户机屏幕默认为 16:9（高 208，约 370×208），3D 视野向左右扩展，菜单仍居中显示原 176×208 画面；`ISLAND_SCREEN=native` 恢复 176×208，也可用比例（如 `21:9`）或 `WxH`（如 `480x208`）指定。HUD：血量在左上角（3/4 尺寸），子弹数和物品提示在右上角，菜单提示在右下角。颜色：默认 sRGB（交换链为 `*_SRGB` 格式时由硬件编码），`ISLAND_COLORSPACE=p3` 在表面支持 Display-P3 时输出 P3。

1. 等标题显示「按 OK 键进入」，按右 Shift。主菜单选「新的开始」，再按右 Shift。确认开局影片播放，随后进入有角色、石阶和 HP 栏的序章场景。
2. 等每段对白显示完再按右 Shift，包括船锚特写。用 Esc 逐页关闭方向和奔跑教程；第一张教程关闭后可能短暂看到场景，再弹出下一页。等两页均已关闭，画面稳定显示「物品／菜单」，再测试移动。
3. 分别短按左右键，确认朝向随按键改变；按住上键走一小段，松键后应停止行走。继续在序章内探索，尝试一处原版脚本互动；确认画面和输入持续正常，没有黑屏、冻结、异常退出或卡住进度的问题。无需联网。

**通过条件**：序章确实加载，教程后可以持续游玩，无阻断进度的异常。进入第一章及存读档需要独立验证，不从序章结果推断。若失败，记录提交号、卡住前按的键、最后可见画面，以及 `runtime.log` 首条相关错误；不要公开存档、授权文件或完整的本机路径。
