# PC 版现代化需求

本文记录已确定的 PC 版方向。当前只定义需求和边界，不实现玩法修改或具体图形 API。

- [宿主抽象设计](pc-host-abstraction-design.md)

## 总原则

- 保留原游戏的剧情、脚本、地图、模型、贴图、镜头语义、碰撞、互动判定和存档语义。
- 原 Symbian 平台实现、软件光栅器、旧媒体后端和设备接口不作为 PC 版最终架构；它们只保留为兼容层、行为参考或对照实现。
- 不擅自增加多边形、不改低模风格、不用 AI 或人工重绘替换原资产。
- 玩法替代（相机、麦克风等）暂不实现；本阶段只讨论和规划纯图形现代化及 PC 输入布局。

## 图形需求

### 现代 3D 管线

使用现代图形 API 接管完整的 3D 渲染管线，而不是继续把 CPU 软件光栅化结果作为最终架构：

```text
原游戏场景/对象/镜头语义
  -> 现代 GPU 顶点变换、裁剪、光栅化、深度测试
  -> 原版风格的材质、透明、光照和雾效
  -> HUD、对话和其他 2D 层合成
  -> PC 窗口呈现
```

原 CPU 渲染器保留为对照基线。现代后端必须先复现其可观察行为，再逐项启用增强效果；不能仅凭画面大致相似就替换遮挡、透明和合成规则。

### 真 3D 边界

原场景按三维顶点、物体网格、镜头变换和三角形深度关系工作，不按 Doom 式二维墙面/扇区模型重建。BSP 继续服务于地图组织、碰撞和空间查询，但不是现代渲染器的限制。

### 宽屏

- 支持宽屏和非 4:3 窗口。
- 过场动画不拉伸、不裁切，按素材比例显示，必要时留黑边。
- 可玩场景优先保持原镜头语义；横向扩展不得改变剧情镜头、碰撞或交互判定。
- HUD、对白框和菜单采用安全区域锚定，避免随着画幅扩展跑到屏幕边缘。

### 抗锯齿与纹理过滤

- 支持现代硬件抗锯齿；具体 MSAA、TAA 或其他方案由后端验证决定。
- 保留原贴图尺寸、纹理内容和低模几何，不增加多边形或细分模型。
- 允许使用合理的 mipmap、各向异性过滤和柔和采样，让非像素风贴图减少毛边和闪烁。
- 不对整帧做不可控的模糊；文字、HUD、镂空材质边缘必须保持可读和稳定。

### 光照、雾和渲染范围

- 维持原版光照风味，不引入与资产风格冲突的现代写实光照。
- 默认支持远大于原版的渲染范围；不因远裁剪面过近而隐藏已有地图几何。
- 雾效提供三个设置：
  - **原版风味**：尽量复现原版颜色、距离和衰减感。
  - **更沉浸**：保留氛围但调整衰减，使远处更早变暗/隐去，强化恐怖感。
  - **关闭**：移除距离雾；保留其他原始光照和材质效果。
- 雾设置只改变渲染，不改变地图边界、碰撞、AI、脚本和交互距离。
- 远景若暴露未制作区域，应通过地图边界、天空/背景层或保守裁剪处理，不伪造新场景资产。

## PC 输入与装备布局

输入现代化不等于修改道具和谜题规则。原有物品、使用条件、合成配方和脚本结果保持不变。

| 操作 | 需求 |
| --- | --- |
| `Q` | 装备镐子；未获得时不给出错误使用结果，不强制切换到其他物品。 |
| `E` | 装备弹弓；未获得时行为同上。 |
| `F` | 切换到当前剧情互动明确需要的物品；只选中，不自动使用。若存在多个合理候选，不替玩家揭示答案。 |
| `Tab` | 打开/关闭背包。背包打开时暂停世界更新，输入不传递给场景。 |
| 鼠标左键 | 点击可直接使用的物品；对需要目标的物品，选中后返回场景选择目标。 |
| 鼠标拖拽 | 将物品 A 拖到物品 B，交给原有合成规则判定；失败时不消耗、不触发单击使用并恢复原位置。 |

背包 UI 应支持鼠标操作，但不能绕过原脚本的成功、失败、取消和存档更新路径。暂停背包期间，是否暂停音频、影片和非世界 UI 需要按原状态机分别定义，不能假设全部线程停止。

## 明确不在本阶段

- 不实现相机替代玩法、麦克风替代玩法或无硬件互动补丁。
- 不修改剧情脚本、谜题判定、碰撞、角色运动和存档格式。
- 不增加新模型面数、重绘贴图或改变原始资产内容。
- 不把现代化渲染和玩法模组系统混为同一层。

## 验收顺序

1. 原软件渲染与现代后端在同一输入下通过序章基线：场景、遮挡、深度、透明、贴图和 HUD。
2. 现代后端验证宽屏窗口，确认过场保持比例、可玩场景无裁切异常、HUD 锚定稳定。
3. 分别验证抗锯齿、柔和纹理过滤和三档雾设置；每项都不得改变脚本和碰撞结果。
4. 验证 Q/E/F/Tab、点击使用和拖拽合成；使用原有道具规则，不引入新的剧情分支。
5. 序章、第一章转场和存档分别报告；不能用序章结果代替第一章或存档验收。
